# Submission item 1 — Exact prompt(s) given to the AI tool

**AI tool used:** Claude (Anthropic)

**Prompt:**

```
Write a React component using Apollo Client's useQuery hook that fetches a list of food
categories from a GraphQL API (https://graphqlzero.almansi.me/api) and shows them as filter
chips under a page heading. Use useState to track the active category and highlight the
selected chip with a different background/border colour. Filter a hardcoded array of food
item objects by the selected category and render only the matching items in real time as the
user clicks. Handle useQuery's loading state (spinner) and error state (readable message)
before rendering the chips. Use plain JavaScript (no TypeScript).
```
